# Как ускорить и улучшить ЛОМБАРД

## Зачем это нужно?
- Клиенту нужны деньги «вчера» — скорость решает
- 80% заходят с телефона — сайт должен работать на 3G
- SEO-трафик: запросы «срочный залог», «деньги под залог часов»

## Что будем ускорять?

| Что именно | Как упростим |
|------------|---------------|
| Фото вещей (золото, часы, бренды) | Сжимаем в WebP, отдаём через CDN, проверяем качество (не размыто) |
| Оценка ИИ | Предобученная модель на сервере, ответ < 1 секунда |
| Загрузка паспортных данных | Сканер паспорта по камере (поле ввода заполняется автоматически) |
| Подписание залогового билета | Простая ЭП через СМС (как у Операторов связи) |
| Онлайн-продление займа | Кнопка в личном кабинете — списываем проценты с карты |
| Проверка должников | Кэшируем результат ФССП на 24 часа |
| Чат с оценщиком | WebSocket, без перезагрузки страницы |

## Как будем делать?

1. Проверим скорость через Lighthouse, Pagespeed, WebPageTest.
2. Внедрим Service Worker — клиент видит статус заявки даже без интернета.
3. Настроим HTTP/2 и Brotli.
4. Фото вещей храним 90 дней (срок залога), потом удаляем.
5. Автоматический скоринг клиента по базе должников (без задержки).
6. Кэшируем оценку популярных моделей (iPhone, Rolex, Tissot) на сервере.
7. При повторном обращении клиента — показываем предыдущие займы, не просим паспорт снова.
