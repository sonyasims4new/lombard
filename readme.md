# ЛОМБАРД — онлайн-ломбард с быстрой оценкой и выдачей денег

## Что это такое

ЛОМБАРД — это сервис, где можно сдать ценные вещи (золото, часы, технику, брендовую одежду) в залог и получить деньги на карту за 15 минут.  
Клиент загружает фото — ИИ определяет категорию, бренд, состояние и предлагает предварительную сумму займа.  
Оценщик подтверждает за 5 минут в чате. Деньги сразу на карту.

## Главные возможности

### Для клиента (заёмщика)
- Получить деньги за 15 минут без очередей
- Бесплатная курьерская доставка вещи в ломбард (от 5000 ₽ займа)
- Онлайн-залоговый билет с QR-кодом и печатью
- Продлить залог онлайн без визита в офис
- Вернуть вещь — курьер привезёт обратно за счёт ломбарда
- Ставка от 0.3% в день (ниже, чем в МФО)

### Для ломбарда (владельца бизнеса)
- Автоматическая проверка подлинности золота/часов/брендов через ИИ + эксперт
- Интеграция с Единой базой ломбардов (ФНС) — выгрузка залогов автоматически
- Скоринг должников (ФССП, кредитная история)
- Страхование залога на 100% суммы
- Чёрный список недобросовестных клиентов

### Логистика и хранение
- Курьер (СДЭК, DPD, Почта России) забирает вещь за наш счёт
- Терминалы приёма в городах-миллионниках (как постаматы, но для ценностей)
- Сейфовое хранение с круглосуточной охраной
- Если клиент не выкупил — вещь уходит на торги (своя площадка + Avito)

### Для партнёров (сетевые ломбарды)
- API для интеграции с 1С, МоегоСклада, RetailCRM
- Белая бухгалтерия (чеки, КУДиР, отчётность в ФНС)
- Рекламный бюджет на привлечение клиентов (Яндекс.Директ, Авито)
